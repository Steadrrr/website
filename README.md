# 휴양림 업무일지 시스템

휴양림 현장 근무자(사원·공무직)가 **일일업무일지 / 일일매출보고 / 시설물관리일지**를
웹으로 작성하고, 다른 사무실의 **주무관 → 팀장**이 순서대로 온라인 결재하는 사이트입니다.

- PHP 8.4 + MariaDB (utf8mb4), 프레임워크·Composer 없이 파일 업로드만으로 동작
- 대시보드: 입장권(무료/유료/합계)·객실(판매객실/입실인원)을 일별/주별/월별 그래프로 표시 (Chart.js)
- 상품관리: 입장권·객실 상품과 가격(객실: 비수기 평일/비수기 주말/성수기, 요금구분별 할인율), 객실 최대인원·요금구분별 상품권 환급액, **기간요금**(객실 성수기 7~8월, 입장권 동절기 11~2월 등)을 관리자가 직접 편집
- 매출보고: 상품 단가·기간요금 자동 입력, 할인 체크, 입실인원, 입장권 현금/카드, 객실별 지역상품권 환급(기준 환급액과 다르면 알림)
- 시설물: 관리팀(휴양림팀·산림문화팀) > 구역·건물 > 세부시설, 사진·스펙 관리, 팀별 점검일지, 시설별 이상 이력 조회
- 장비관리: 신규 등록, 사진·스펙, 점검·수리·관리 이력, 수리중/불용 처리
- 매출통계: 기간별·월별·연간 매출 통계, 업무일지 목록 → **엑셀 다운로드**, **인쇄 / PDF 저장**
- 지역상품권 재고·수불부: 입고는 결재완료 시, 출고는 매출보고 상신 시 자동 반영
- 전결: 전결 권한을 받은 주무관은 팀장 부재 시 최종 결재 가능
- 일지 수정: 상신된 모든 일지는 **모든 직원이 수정** 가능. 수정하면 결재가 처음부터 다시 진행되고 '수정됨' 표시와 수정 이력(수정 전·후 비교)이 남음
- 공지사항: 게시판 + 대시보드 맨 위에 중요·최근 공지 표시
- 조직도: (회원관리에서 '조직도 숨김'을 체크한 최고관리자·테스트 계정은 표시 안 함) 상위 부서(팀장·주무관) → 사업장 → 팀(공무직) → 반(반장·반원) 구조로 사진·이름·직급·보직·전화번호 표시.
  대시보드 왼쪽에 로그인한 직원의 사진·이름·소속·보직 표시
- 일정표: 구글 캘린더 스타일 월간 달력·목록, 누구나 작성, 행사·공사·프로그램·기타 색상 구분
- 근태관리(사원): 달력에서 연차·병가·공가·결근(하루 단위), 조퇴·외출·초과근무(시간 단위) 입력 → 일지와 같은 결재선으로 결재.
  입사일 기준 연차 자동 발생·당겨쓰기 한도, 병가 한도·진단서 안내, 공휴일·휴관일 공유, 개인 월간 근태표 엑셀·인쇄
- 메뉴: 대시보드 · 일정표 · 근태관리(근태 달력·개인 월간 근태표) · 운영관리(업무일지·매출보고·상품권·매출통계·객실이용통계·유실물관리) · 프로그램(산림치유센터·유아숲체험원·유아숲(직영)·숲해설·프로그램 통계) · 시설관리(시설점검·시설물·장비) · 기타(공지사항·조직도·결재함)
- 설정 메뉴(최고관리자): 기본 정보, 조직 구성(팀·반), 회원관리, 상품·요금, 시설 구역·건물, 장비 분류를 한곳에서 관리
- 각 일지: 달력 화면에서 날짜별 조회·작성, 결재 상태를 색으로 표시
- 회원가입 → 관리자(팀장) 승인 → 직급 지정
- 결재란(도장칸) 표시, 인쇄용 화면 지원, 모바일 화면 대응

## 1. 왜 워드프레스/그누보드를 쓰지 않았나

호스팅의 자동설치(워드프레스, 그누보드)는 **게시판·블로그용**입니다.
이 시스템의 핵심인 "직급별 결재선(사원 → 공무직 → 주무관 → 팀장)", "매출 숫자 집계 그래프",
"일지별 달력 조회"는 두 프로그램 모두 기본 기능에 없어서 결국 플러그인/스킨을 대부분
새로 짜야 합니다. 그래서 **필요한 기능만 담은 가벼운 PHP 프로그램**으로 만들었고,
호스팅에는 자동설치 없이 **빈 PHP 호스팅 + DB**만 있으면 됩니다.

> 자동설치에서 이미 워드프레스/그누보드를 설치했다면 지우거나, 이 프로그램을
> 하위 폴더(예: `/worklog`)에 올려 따로 쓰면 됩니다.

## 2. 서버(호스팅) 세팅 방법

카페24·가비아·닷홈 등 국내 웹호스팅 기준입니다. 메뉴 이름은 업체마다 조금 다릅니다.

### 2-1. 호스팅 신청 시
| 항목 | 설정 |
|---|---|
| PHP 버전 | **8.4** (관리화면 "PHP 버전 변경"에서 확인) |
| DB | MariaDB 10.x, 문자셋 **utf8mb4** (UTF-8) |
| 자동설치 | **선택 안 함** (빈 호스팅으로) |
| 트래픽 | 월 150G면 충분 (일지 텍스트 위주, 직원 수십 명 기준 수 GB 이하) |

### 2-2. 도메인 & SSL(https)
1. 도메인을 연결합니다. (호스팅 제공 임시 도메인으로 먼저 테스트해도 됩니다)
2. 관리화면에서 **무료 SSL(Let's Encrypt)** 을 신청합니다.
   로그인 비밀번호가 오가므로 **https는 필수**입니다.
3. SSL 적용 후 `.htaccess` 아래쪽의 https 강제 이동 3줄 주석(`#`)을 지웁니다.

### 2-3. DB 만들기
- 대부분의 호스팅은 신청 시 DB가 자동 생성됩니다(보통 DB명 = FTP 아이디).
- 관리화면에서 **DB명 / DB 아이디 / DB 비밀번호 / DB 호스트(대개 localhost)** 를 확인해 둡니다.
- phpMyAdmin이 있다면 DB의 기본 정렬(Collation)이 `utf8mb4_unicode_ci` 또는
  `utf8mb4_general_ci` 인지 확인합니다.

### 2-4. 파일 올리기 (FTP)
1. [FileZilla](https://filezilla-project.org/) 로 FTP 접속 (호스트/아이디/비밀번호는 호스팅 관리화면 참고)
2. 웹 루트 폴더(카페24: `www`, 가비아/닷홈: `html` 또는 `public_html`)에
   이 리포지토리의 파일 전체(`.git` 폴더 제외)를 올립니다.
   - 하위 폴더로 쓰려면 `www/worklog/` 처럼 폴더를 만들어 그 안에 올리고, 아래 설정의 `base_url`을 `'/worklog'`로 지정합니다.
3. `.htaccess` 파일(점으로 시작, 숨김파일)도 빠짐없이 올라갔는지 확인합니다.
4. **`uploads` 폴더 권한을 707로** 바꿉니다 (FileZilla에서 폴더 우클릭 → 파일 권한 → 707).
   시설물·장비 사진이 이 폴더에 저장됩니다. 권한이 없으면 사진 저장 시 안내 메시지가 나옵니다.

### 2-5. 설정 파일
1. `app/config.sample.php` 를 복사해 **`app/config.php`** 로 저장
2. DB 정보, 사이트 이름, `base_url` 을 입력
3. 상품·가격·기간요금, 시설물, 장비는 설치 후 각 관리 화면에서 등록합니다 (config.php에서 바꿀 것은 거의 없음)

### 2-6. 설치 실행
1. 브라우저에서 `https://도메인/install.php` 접속
2. 최고관리자 아이디/비밀번호/이름 입력 → 테이블 생성 + 관리자 계정(팀장 직급) 생성
3. **설치 후 `install.php` 파일을 FTP에서 반드시 삭제**합니다.
   (이미 회원이 있으면 다시 실행되지 않지만, 삭제가 안전합니다)

### 2-7. 운영 시작
1. 직원들에게 사이트 주소를 알려주고 **회원가입**하게 합니다.
2. 최고관리자가 **설정 › 조직 구성**에서 팀과 반을 만들고, **설정 › 기본 정보**에서 상위 부서·사업장 이름을 확인합니다.
3. 관리자(또는 팀장)가 **회원관리**에서 직급을 확인하고 **팀·반·반장·보직**을 입력한 뒤 상태를 "사용"으로 바꾸면 로그인 가능합니다.
   (팀·반·보직은 회원가입 화면에는 없고 회원관리에서만 입력합니다. 본인은 '내 정보'에서 확인만 할 수 있습니다)
   전결을 맡길 주무관은 **전결권한**에 체크합니다.
4. 최고관리자가 **설정 › 상품·요금**에서 입장권과 객실(3가지 요금·최대인원·상품권 환급액)을 등록하고 할인율을 확인합니다.
   상품이 없으면 매출보고를 작성할 수 없습니다.
   기간요금(객실 성수기 7/1~8/31, 입장권 동절기 11/1~2/29)은 기본으로 만들어져 있으니 입장권의 동절기 가격을 확인하세요.
5. **상품권 → 입고 등록**에서 현재 보유 중인 지역상품권을 '기초재고'로 한 번 올려 결재받습니다.
6. 최고관리자가 **설정 › 시설 구역·건물**에서 팀별 구역·건물을 만들고, 주무관 이상이 **시설물 → + 세부시설 등록**으로 점검할 시설을 등록합니다.
   (등록한 시설이 시설점검일지의 점검표가 됩니다)
7. 최고관리자가 **설정 › 장비 분류**에서 분류를 만들고, 주무관 이상이 **장비** 메뉴에서 보유 장비를 등록합니다.
8. 현장 PC/휴대폰에서 바탕화면·홈화면 바로가기를 만들어 두면 편합니다.

### 2-8. 새 버전으로 업데이트하는 방법
1. **먼저 DB 백업** (phpMyAdmin → 내보내기)
2. FTP로 새 파일을 덮어쓰기합니다. **`app/config.php`는 올리지 마세요** (서버의 설정을 그대로 사용).
   **`uploads` 폴더 안의 사진도 서버 것을 그대로 두세요** (덮어쓰거나 지우지 않기).
3. 아무 페이지나 한 번 접속하면 DB가 자동으로 업그레이드됩니다(새 테이블·컬럼 추가, 기존 자료 유지).
4. 이전 버전에서 작성한 매출보고는 그대로 조회됩니다. 객실 요금 3구분 업데이트 시 기존 '주말·성수기' 요금은
   비수기 주말과 성수기 요금에 똑같이 채워지므로 **상품관리에서 성수기 요금과 상품권 환급액을 입력**해 주세요.
   (대시보드의 입장권·객실 집계는 새 형식 매출보고부터 반영)

### 문제 해결: 사이트가 열리지 않을 때 (HTTP ERROR 500 등)
브라우저에서 **`https://도메인/check.php`** 를 여세요. PHP 버전, 필요한 PHP 기능, 파일 누락, `app/config.php` 문법·DB 접속,
기존 자료, uploads 폴더 권한을 점검해서 빨간색으로 원인과 해결 방법을 보여 줍니다. (비밀번호는 표시하지 않음)

자주 있는 원인:
- **서버 파일을 전부 지우고 다시 올린 경우**: `app/config.php`(DB 정보)는 GitHub에 없으므로 다시 만들어야 합니다.
  `app/config.sample.php` 를 복사해 `config.php` 로 이름을 바꾸고 DB 정보를 넣어 `app` 폴더에 올리세요.
  `uploads` 폴더 권한(707)도 다시 설정하고, 사진은 호스팅 파일 백업으로 복구하거나 다시 올려야 합니다.
  **install.php 는 실행하지 마세요** (자료가 있으면 실행되지 않습니다).
- PHP 버전이 8.1 미만으로 바뀐 경우 → 호스팅 관리화면에서 8.4로 변경
- config.php 의 따옴표·쉼표 누락, 메모장 저장 시 BOM → check.php 가 줄 번호와 함께 알려 줍니다.

### 2-9. 백업
- 호스팅의 **DB 자동백업** 기능을 켜 두세요.
- 월 1회 정도 phpMyAdmin → 내보내기(Export)로 `.sql` 파일을 받아 별도 보관을 권장합니다.

## 3. 권한 & 결재 구조

| 직급 | 값 | 작성 | 결재 | 회원관리 |
|---|---|---|---|---|
| 팀장 | 4 | O (작성 즉시 결재완료) | 2차(최종) 결재 | O (회원·상품관리, 시설물·장비) |
| 주무관 | 3 | O (팀장 결재) | 공무직 다음 결재, **전결권한** 있으면 전결 | 시설물·장비 등록/수정/불용 |
| 공무직 | 2 | O | 사원 문서의 1차 결재 | - (장비 점검·수리 이력 기록은 가능) |
| 사원 | 1 | O | - | - (장비 점검·수리 이력 기록은 가능) |
| 최고관리자 | `is_admin` | 사이트 관리 계정. 모든 일지 삭제, 관리자 지정 가능 | | O |

결재선은 작성자 직급으로 자동 결정됩니다.

```
사원 작성   ──상신──▶ 공무직 승인 ──▶ 주무관 승인 ──▶ 팀장 승인 ──▶ 결재완료
공무직 작성 ──상신──────────────────▶ 주무관 승인 ──▶ 팀장 승인 ──▶ 결재완료
                          (어느 단계든 반려 가능, 사유 필수) → 작성자가 수정 후 재상신
주무관 작성 ──상신──▶ 팀장 승인 ──▶ 결재완료
팀장 작성  ──저장──▶ 결재완료

[전결] 팀장 부재 시: … ──▶ 주무관 '전결' ──▶ 결재완료 (결재란 팀장 칸에 '전결' 표시)
```
- 공무직 결재는 공무직 누구나 할 수 있습니다 (결재함에 사원이 올린 문서가 나옵니다).
- **일괄 결재** (기타 › 결재함): 결재 대기 문서를 체크박스로 여러 개 고르거나 **전체선택**한 뒤 **선택 문서 승인**으로 한 번에 승인합니다.
  전결권한이 있는 주무관에게는 **선택 문서 전결** 버튼도 나옵니다 (전결할 수 없는 문서는 건너뜀). 의견을 적으면 선택한 문서 모두에 남습니다.
  반려는 사유가 필요하므로 문서를 열어 하나씩 처리합니다.

- 전결은 회원관리에서 **전결권한**에 체크한 **주무관**만 할 수 있습니다.
- 주무관 본인이 작성한 문서는 전결할 수 없습니다(자기 결재 방지). 팀장 결재가 필요합니다.

문서 상태: `임시저장`(본인만 보임) → `결재중` → `결재완료` / `반려`

- **수정**: 결재를 올린 일지(결재중·결재완료·반려)는 **모든 직원이** 목록·상세 화면의 '수정' 버튼으로 고칠 수 있습니다.
  직급과 관계없이 가능합니다 (예: 사원이 공무직·주무관이 쓴 일지 수정).
  - 수정 버튼을 누르면 "결재 상태가 초기화됩니다" 확인창이 뜨고, 수정 화면 위에도 안내가 표시됩니다.
  - 저장하면 기존 결재가 모두 취소되고 **수정한 사람의 직급 기준으로 처음부터 다시** 결재가 올라갑니다
    (사원이 수정 → 공무직 → 주무관 → 팀장, 공무직이 수정 → 주무관 → 팀장, 주무관이 수정 → 팀장, 팀장이 수정 → 바로 결재완료).
  - 상태 옆에 **'수정됨'**(2회 이상이면 횟수) 표시가 붙고, 달력에는 ✎ 표시가 붙습니다.
  - 상세 화면 아래 **수정 이력**에 수정한 사람·일시·사유, 수정 전 결재 상태, 항목별 수정 전/후 내용이 남습니다.
  - 바뀐 내용 없이 저장하면 결재 상태는 그대로 둡니다.
  - 상품권입고 문서를 수정하면 다시 결재완료될 때까지 그 입고분은 재고에서 빠집니다.
- 임시저장 문서는 작성자만 보고 수정할 수 있습니다. 삭제는 작성자(임시저장·반려 상태) 또는 최고관리자만 가능합니다.
- 매출보고는 **하루 1건**만 등록됩니다(그래프 중복 집계 방지).
- 대시보드에는 기본적으로 결재중+결재완료 매출보고가 포함됩니다.
  결재완료만 보려면 `config.php`의 `chart_statuses`를 `['approved']`로 바꿉니다.

## 4. 매출보고 · 상품 · 지역상품권

### 상품관리 (관리자·팀장, 메뉴: 상품관리)
| 구분 | 입력 항목 |
|---|---|
| 입장권 | 상품명, 유료/무료, 가격, 표시순서, 판매 여부 |
| 객실 | 객실명, **객실 분류**(2인실·4인실·독채 등, 객실 표 아래에서 추가·수정), 최대인원, **비수기 평일 · 비수기 주말 · 성수기** 요금, 같은 3구분별 **지역상품권 환급액**, 표시순서, 판매 여부 |
| 시설대관 | 시설명, 대관 시간별 요금(**2시간 · 4시간 · 4시간 이상(18시까지)**), **야간(18~21시) 추가요금**, 표시순서, 판매 여부 |
| 대관 숙박시설 | 시설명, **정액 요금**, 표시순서, 판매 여부 (할인은 매출보고에서 시설대관과 합쳐 통합 할인) |
| 객실 할인율 | 요금구분별로 일괄 적용 (기본: 비수기 평일 30%, 비수기 주말 10%, 성수기 10%). 할인가는 10원 단위 버림 |

- 가격을 바꿔도 **이미 작성된 매출보고 금액은 바뀌지 않습니다** (작성 당시 상품명·단가를 함께 저장).
- 매출보고에 쓰인 상품은 삭제할 수 없고, '판매' 체크를 해제해 목록에서 숨깁니다.

### 기간요금 (상품관리 페이지 아래쪽)
| 대상 | 예 | 적용 |
|---|---|---|
| 입장권 | 동절기 11-01 ~ 02-29 | 입장권 표에 '동절기 가격' 열이 생기고, 기간 중 매출보고에 그 가격이 자동 입력 (비우면 정상가) |
| 객실 | 성수기 07-01 ~ 08-31 | 기간 중 매출보고에서 '성수기' 요금이 자동 선택 |

기간은 월-일로 입력하고 해를 넘겨도 됩니다. 업데이트 시 이미 등록된 유료 입장권의 동절기 가격은 정상가의 50%로 채워 둡니다.

### 매출보고 작성
- **입장권**: 수량만 입력하면 단가 × 수량이 자동 계산됩니다. 무료 상품은 0원으로 매수만 집계됩니다.
  - 동절기처럼 **기간요금**이 걸린 날짜는 기간 가격이 자동으로 들어갑니다(제목 옆에 '동절기 요금 적용' 표시).
  - **현금**: 현금으로 받은 금액을 적으면 카드 금액(합계 − 현금)이 자동 계산됩니다. 현금이 없으면 비워두세요.
- **객실**: 객실명마다 한 실이므로 객실수는 없고, 판매한 객실의 **입실인원**만 입력하면 판매로 잡힙니다.
  - 요금구분은 날짜로 자동 선택: 성수기 기간(7/1~8/31) → 성수기, 그 외 금·토요일 → 비수기 주말, 나머지 → 비수기 평일.
    공휴일 전날 등은 직접 바꾸면 됩니다.
  - **할인** 체크 시 그 요금구분의 할인율이 자동 적용 (예: 비수기 평일 60,000원 → 30% 할인 42,000원)
  - 입실인원이 최대인원을 넘으면 저장되지 않습니다.
- **쉬자파크숙박(입실) · 쉬자파크숙박(퇴실)**: 입장권 표 아래에 항상 있는 **자동 상품**(무료)입니다. 수량을 직접 입력하지 않습니다.
  입실 = 이 보고서 객실 판매의 **입실인원 합계**, 퇴실 = **전날** 매출보고의 입실인원 합계. 입장권 합계(무료)에 포함되어 대시보드·통계에도 들어갑니다.
  전날 보고서를 고치거나 지우면 다음 날 보고서의 퇴실 인원도 자동으로 다시 맞춰집니다. 상품관리에서 수정·삭제할 수 없습니다(🔒).
- **시설대관**: 시설마다 대관 시간(2시간/4시간/4시간 이상)을 고르고 야간 사용이면 '야간'에 체크(야간만도 가능). 단가 = 시간 요금 + 야간 추가요금, 건수를 비우면 1건.
- **대관 숙박시설**: 이용한 **실 수**를 입력합니다 (정액 요금 × 실 수).
- 시설대관과 대관 숙박시설은 **한 덩어리**로 소계를 내고, **통합 할인**을 합계에 한 번에 적용합니다 (줄마다 10원 단위 버림).
  | 할인 기준 | 할인율 | 선택 |
  |---|---|---|
  | 대관 숙박시설 5실 이상 | 10% | 실 수를 넣으면 자동 적용 |
  | 대관 숙박시설 9실 이상 | 20% | 실 수를 넣으면 자동 적용 |
  | 초등·청소년 20명 이상 | 30% | '초등·청소년 20명 이상' **체크** (체크하면 실 수 할인 대신 30%) |
  할인은 한 가지만 적용됩니다. 할인 기준·할인액은 결재 문서와 수정 이력에 남고,
  시설대관·대관 숙박시설 금액(할인 후)은 매출 합계와 통계(시설대관 건수·금액, 시설대관별 표·엑셀 시트)에 들어갑니다.
- **지역상품권 환급**: 객실 판매 표의 오른쪽 칸에 객실별로 환급한 권종별 매수(1천원·5천원·1만원권)를 입력합니다.
  - 환급액이 그 객실의 **기준 환급액**(상품관리의 요금구분별 환급액 — 그 행에서 고른 요금구분 기준)과 다르면 행이 붉게 표시되고, 저장할 때 **팝업으로 확인**합니다.
    (그래도 저장할 수 있고, 저장 후 상단에 '확인 필요' 안내가 남습니다)
  - 표 아래에 **환급 합계(권종별 매수·금액)와 남은 재고(매수·금액)**가 실시간으로 표시됩니다. 재고보다 많으면 붉게 표시되고 저장 시 알립니다.
- 금액은 화면에서 미리 보여주지만, 저장할 때 서버가 상품 가격으로 **다시 계산**합니다.

### 지역상품권 재고 (메뉴: 상품권)
- 권종별(1천원·5천원·1만원) 현재고와 재고 금액
- **수불부**: 월별로 전월 이월 → 입고/출고 내역(문서 링크) → 입고 계·출고 계 → 월말 재고
- **입고**: '입고 등록'으로 상품권입고 문서를 작성 → 결재(주무관 → 팀장, 또는 전결) **완료 시 재고 반영**
- **출고**: 매출보고의 객실별 환급 입력분이 결재를 올리는 즉시 반영 (반려되어도 실제 지급된 것으로 보고 유지, 수정 시 갱신)
- 권종은 `config.php`의 `voucher_denoms`에서 바꿀 수 있습니다.

## 4-0-0. 회원별 메뉴 권한 (회원관리 › 메뉴 권한)
- **사원**마다 **근태관리 · 운영관리 · 프로그램** 메인메뉴를 체크박스로 켜고 끕니다. 공무직·주무관·팀장·최고관리자는 항상 전체 메뉴가 보입니다. 끈 메뉴는 상단 메뉴에서 사라지고 해당 페이지에도 들어갈 수 없습니다
  (운영관리를 끄면 대시보드의 판매 현황·오늘 일지 현황도 숨김, 근태관리를 끄면 '+ 근태 입력' 버튼도 숨김).
- 대시보드·일정표·시설관리·기타(공지·조직도·결재함)는 항상 보입니다. 결재함에서 결재 문서를 보고 승인·반려하는 것은 메뉴 권한과 관계없이 됩니다.
- 새로 가입한 회원과 업데이트 전 회원은 전부 켜진 상태입니다. 최고관리자는 항상 전체 메뉴가 보입니다.

## 4-0-1. 일정표 (메뉴: 일정표)
- 구글 캘린더처럼 **월 달력**과 **목록**으로 봅니다. 왼쪽에 '+ 만들기', 작은 달력, 분류 필터가 있습니다.
- 분류: **행사**(파랑) · **공사**(주황) · **프로그램**(초록) · **기타**(보라). 분류 체크를 끄면 그 분류가 달력에서 숨겨집니다(브라우저에 기억).
- **누구나** 일정을 만들 수 있습니다. 달력의 빈 칸을 누르면 그 날짜로 만들기 창이 열립니다.
  제목·분류·시작/종료일·종일 여부(아니면 시간)·장소·설명을 입력합니다.
- 여러 날 일정은 날짜를 가로지르는 막대로, 시간이 있는 하루 일정은 ● 시간 제목으로 표시됩니다.
  하루에 일정이 많으면 '+N개 더보기'를 눌러 전체를 봅니다. 날짜 숫자를 누르면 그날 일정 목록이 나옵니다.
- 일정을 누르면 내용을 보고, **작성자·주무관 이상·최고관리자**는 수정(✎)·삭제(🗑)할 수 있습니다.
- 대시보드: 공지사항 아래에 **오늘의 일정**(오늘 진행 중인 여러 날 일정 포함, "+ 일정 추가"로 바로 만들기),
  왼쪽에 내일부터 2주 안의 **다가오는 일정**이 표시됩니다. 인쇄 가능.

- 분류 **공휴일**(빨강)·**휴관일**(회색)은 **최고관리자만** 등록·수정합니다. 근태관리 달력과 공유되고, 공휴일은 근태의 근무일에서 빠집니다.
- 왼쪽 **근태 (사원)** 체크로 사원 근태(결재중·결재완료)를 함께 보거나 숨기고, '근태: 팀' 선택으로 팀별로 봅니다. 근태를 누르면 결재 문서로 갑니다.

## 4-0-2. 근태관리 (메뉴: 근태관리)
대상은 **사원**입니다. 근태 1건이 결재 문서 1건이며, 결재선은 일지와 같습니다
(입력한 사람 기준: 사원 → 공무직 → 주무관 → 팀장, 공무직 → 주무관 → 팀장, 주무관 → 팀장, 팀장 → 바로 결재완료). 결재함·대시보드 결재대기에 함께 나옵니다.

**먼저 할 일 — 근무 설정** (⚙ 설정 › 회원관리, 또는 팀장의 기타 › 회원관리): 사원 줄의 **근무 설정 [입력]** 을 눌러
입사일, **계약만료일**(근무 마지막 날, 필수 — 예: 10월 31일까지 일하는 사람은 10-31), 근무 시작·종료 시각, 휴무 요일(매주 쉬는 요일, 여러 개 선택)을 입력합니다.
입력 전에는 휴무를 토·일로 계산하고, 입사일이 없으면 연차·병가를 입력할 수 없습니다.

| 종류 | 단위 | 입력할 수 있는 사람 | 비고 |
|---|---|---|---|
| 연차 | 하루 | 본인, 공무직 이상 | 휴무일·공휴일 제외 근무일만 일수로 셈 |
| 병가 | 하루 | 본인, 공무직 이상 | 한도·진단서 규정 아래 참고 |
| 공가 | 하루 | 본인, 공무직 이상 | 예비군·건강검진 등 |
| 조퇴 · 외출 | 1시간 | 본인, 공무직 이상 | 그 사람의 근무시간 안에서 **1시간 단위로 드롭박스 선택**, **연차에서 차감** (연차 1일 = 8시간). 근무 시작 4시간 뒤 1시간은 점심 휴게시간이라 빠짐 — 예) 9~18시 근무: 9~13시 = 4시간, 9~14시 = 4시간, 13~15시 = 1시간 |
| 결근 | 하루 | **주무관 이상** | 결근한 달은 연차가 발생하지 않음 |
| 초과근무 | 시간 | **공무직 이상** | **공휴일 또는 그 사원의 휴무일**에만. **4시간 근무마다 30분 휴게시간을 뺌** — 예) 9~13시 = 4시간, 9~14시 = 4시간 30분, 9~18시 = 8시간 |

- 사원은 **본인 것만**, 공무직 이상은 모든 사원의 근태를 입력합니다. 입력하면 결재가 바로 올라갑니다.
  같은 사람의 근태가 날짜·시간이 겹치면 입력되지 않습니다. 수정은 없고, **근태 취소** 후 다시 입력합니다
  (본인·입력자는 결재완료 전까지, 주무관 이상·최고관리자는 언제나 취소 가능). 반려된 근태는 계산에서 빠집니다.
- **연차**: 입사일부터 한 달을 결근 없이 채울 때마다(만근) 1일 발생. 계약 개월 수만큼(최대 11일)이 **최대 발생 연차**이며,
  아직 발생하지 않은 연차도 최대 발생 연차까지 **당겨 쓸 수** 있습니다(입력 창에 안내). 사용량에는 결재중인 것도 포함됩니다.
- **병가 한도**(계약기간): 3개월 미만 3일, 3~6개월 미만 6일, 6개월 이상 9일. 한도를 넘으면 입력되지 않습니다.
  병가 기간 중 휴무일·공휴일은 병가 일수에 넣지 않습니다.
  **연속 3일 이상** 또는 **연 6일 초과** 병가는 입력 창과 문서 화면에 **"의사의 진단서를 첨부해야 합니다"** 안내가 나옵니다.
  진단서(사진·PDF)는 입력할 때 또는 나중에 문서 화면에서 첨부하며, 본인·공무직 이상만 열어 볼 수 있습니다
  (`uploads/attendance` 는 주소로 직접 열 수 없게 막혀 있음).
- **근태 달력**: 모든 사원의 근태를 한 달력에 표시(결재중은 테두리만). 팀·근무자별 조회, 종류별 필터.
  공휴일·휴관일이 날짜에 표시되고, 근무자를 고르면 그 사람의 휴무일에 빗금이 칠해집니다.
  왼쪽에 고른 사람(사원은 본인)의 발생·사용·남은 연차와 병가 사용일이 나옵니다. 최고관리자는 '+ 공휴일·휴관일'로 일정표에 바로 등록합니다.
- **개인 월간 근태표**: 날짜별 근무/휴무/공휴일, 근무시간, 근태, 초과근무, 사유와 월 합계, 결재 칸. **엑셀 다운로드**, **인쇄·PDF**.
  사원은 본인 것만, 공무직 이상은 모든 사원의 것을 봅니다.
- **대시보드**: 사원의 왼쪽 프로필에 발생·사용·남은 연차(일·시간)와 병가 사용/한도, '+ 근태 입력' 버튼이 표시됩니다.

## 4-0-4. 프로그램 운영보고 (메뉴: 프로그램)
- **산림치유센터 · 유아숲체험원 · 유아숲(직영) · 숲해설** 네 분야가 매출보고처럼 달력에서 날짜를 골라 **하루 1건**씩 작성하고, 같은 결재선으로 결재합니다
  (사원 → 공무직 → 주무관 → 팀장, 공무직 → 주무관 → 팀장). 상신 후 수정하면 결재가 처음부터 다시 진행되고 수정 이력이 남습니다.
- 보고서 안에 **회차**를 여러 개 입력합니다. 회차 번호는 **1회차부터 자동**으로 붙고, '+ 회차 추가'·'회차 삭제'를 하면 번호가 다시 매겨집니다.
- 회차마다: **단체명(또는 개인 성명)**, **담당자**(직접 입력), **운영시간**, **인원**(남·여 × 유아·초등·중고등·성인·65세이상 — 합계 자동),
  **프로그램 금액**(유료 = 인원 × 5,000원, **할인 = 인원 × 3,000원**, 무료 = 0원), **활동내용**.
  1인 참가비(유료·할인)는 ⚙ 설정 › 기본 정보에서 바꿉니다 (이미 작성된 보고서 금액은 그대로). 통계에 유료·할인·무료 인원이 따로 집계됩니다.
- **활동사진**은 보고서마다 여러 장 첨부하며, 긴 변 1000px 저해상도로 줄여서 저장됩니다.
- 달력 칸에 그날의 '회차 · 인원'이 표시됩니다.
- **프로그램 통계**: 일별 · 주별(월~일) · 월별로 기간과 분야(전체/분야별)를 골라 회차, 남·여, 연령대별 인원, 유료·무료 인원, 금액을 봅니다.
  분야별 합계, 성별·연령별 표가 함께 나오고 **엑셀 다운로드**(기간별·분야별·성별연령별 시트)와 인쇄가 됩니다. '결재완료만' 체크로 결재 끝난 보고서만 집계.

## 4-0-3. 유실물관리 (메뉴: 운영관리 › 유실물관리)
- 유실물을 **액자 모양 갤러리**로 사진과 물품명을 한눈에 봅니다. 상태 배지와 습득일·장소가 함께 표시되고, 본인수령된 것은 흐리게 보입니다.
- **+ 유실물 등록**: 사진, 물품명(필수), 습득일, 습득장소, 습득자, 메모, 상태를 입력합니다.
  저장하면 **유실물 등록번호**가 자동으로 붙습니다: `등록 연도-일련번호` (예: 2026-0001). 해마다 0001부터 시작하고,
  삭제된 번호는 다시 쓰지 않으며 수정해도 바뀌지 않습니다. 갤러리·상세 화면에 표시되고 번호로 검색할 수 있습니다.
  사진은 휴대폰으로 바로 찍어 올려도 브라우저에서 **긴 변 800px 저해상도**로 줄여서 올라가고,
  서버에 GD 확장이 있으면 서버에서도 한 번 더 줄입니다(보통 한 장 20~100KB).
- 상태: **접수 → 연락완료 → 택배발송 → 본인수령**. 상세 화면에서 상태를 누르면 바로 바뀌고, 마지막 수정자·시각이 남습니다.
- 위쪽 탭으로 전체 / 보관 중(본인수령 제외) / 상태별로 보고, 물품명·장소·습득자·메모로 검색합니다.
- 모든 직원이 등록·수정할 수 있고, 삭제는 등록한 사람·주무관 이상·최고관리자만 할 수 있습니다.

## 4-1. 공지사항 (메뉴: 기타 › 공지사항)
- **공무직 이상**(공무직·주무관·팀장·최고관리자)이 공지를 쓰고 수정·삭제할 수 있습니다. 모든 직원이 읽을 수 있습니다.
- **중요 공지**로 체크하면 목록 맨 위에 고정되고 대시보드에 항상 표시됩니다.
- 대시보드 맨 위에는 중요 공지와 최근 30일 공지가 최대 6개 표시됩니다. 3일 이내 공지는 **N** 표시.

## 4-2. 개인 사진 · 조직도
- **개인 사진**: '내 정보' → 사진 올리기 (또는 대시보드 왼쪽 사진을 누르기). 회원관리 권한자(최고관리자·팀장)는
  회원관리 표의 이름을 눌러 다른 직원의 사진도 올릴 수 있습니다. 큰 사진은 자동으로 800px로 줄여서 올라가며,
  바꾸거나 지우면 이전 사진 파일도 서버에서 지워집니다. 사진이 없으면 이름 첫 글자가 표시됩니다.
- **조직도**(메뉴: 조직도): 사진·이름·직급·보직·전화번호(휴대폰에서 누르면 전화 걸기)를 아래 구조로 보여 줍니다. 인쇄 가능.
  ```
  [상위 부서: 양평군청 산림과 산림휴양팀]  팀장 · 주무관 (팀·반과 관계없이 항상 여기)
                  │
  [사업장: 양평쉬자파크]
     ├─ 휴양림팀    맨 위: 공무직
     │    ├─ 숙박반   맨 위: 반장 → 반원
     │    ├─ 시설반   …
     │    └─ 반 미지정 (팀만 정해진 사원)
     └─ 산림문화팀  …
  [소속 미지정]  팀이 없는 공무직·사원
  ```
  팀·반·반장(체크박스)·보직·연락처는 회원관리에서 정합니다. 반을 고르면 팀은 자동으로 맞춰집니다.
- **대시보드 왼쪽**: 로그인한 직원의 사진·이름·직급·팀·보직, 오늘 작성한 일지 수, 내 결재 대기 건수

## 5. 시설물 · 장비

### 시설물 (메뉴: 시설물 / 시설점검)
```
관리팀(대분류)      구역·건물(중분류)         세부시설
휴양림팀      ──┬─ 숲속의집          ──┬─ 101호 보일러 (사진, 스펙)
               │                      └─ 101호 화장실
               └─ 야영장            ──── 개수대
산림문화팀    ──── 산림문화휴양관    ──── 전시실 조명
```
- **시설물** 메뉴: 팀별 구역·세부시설을 사진 카드로 보여주고, 최근 점검결과와 이상 이력 건수를 표시합니다.
  아래에 최근 30일 이상 내역이 모여 있습니다.
- **세부시설 상세**: 사진, 규격·스펙, 결과별 건수, **점검 이상 이력**(정상이 아니었던 기록만, '전체'로 모든 기록), 기간 조회, 인쇄
- **시설점검**(시설물관리일지): 관리팀을 고르면 그 팀의 등록 시설이 구역별로 점검표에 자동으로 나옵니다.
  등록되지 않은 항목은 '기타(직접 입력)'에 적을 수 있습니다. 달력도 팀별로 나눠 볼 수 있습니다.
- 구역·건물, 세부시설 등록·수정은 주무관 이상. 점검 기록이 있는 시설은 삭제 대신 '사용안함' 처리됩니다.
- 점검결과 선택지는 `config.php`의 `facility_results` (첫 번째가 '정상').

### 장비 (메뉴: 장비)
- 팀 > 장비 분류 > 장비. 모델·일련번호·보관 위치·취득일·취득금액·규격·사진
- 상태: **사용중 / 수리중 / 불용**. 목록은 기본으로 불용을 제외하고, 검색(장비명·모델·일련번호·위치) 가능
- **이력**: 점검·수리·관리·정비·기타 기록 (일자, 내용, 비용, 업체). 모든 직원이 기록할 수 있고,
  기록하면서 '수리중' / '사용중(수리 완료)'으로 상태를 바꿀 수 있습니다. 누적 수리·관리비 자동 합산
- **불용처리**(주무관 이상): 불용일·사유 입력 → 목록에서 '불용'으로 분류, 이력은 유지. 잘못 처리했으면 '불용 해제'

### 사진
- 휴대폰으로 찍은 큰 사진은 올리기 전에 브라우저에서 자동으로 줄입니다(긴 변 1600px). 트래픽과 용량 절약.
- `uploads/` 폴더에 저장되며 이 폴더에서는 스크립트가 실행되지 않도록 막혀 있습니다.

## 6-1. 객실이용통계 (운영관리 › 객실이용통계)
- 매출보고의 **객실 판매**(대관 숙박시설 제외)로 판매 객실(실·박), 입실 인원, 1실 평균 인원, 객실 매출, **객실 가동률**,
  평균 객실단가(판매 1실당 매출), RevPAR(객실당 1일 매출), 요금구분(비수기 평일·주말·성수기)·할인 판매를 집계합니다.
- 단위: **일간 · 주간(월~일) · 월간 · 연간**. **기간 A**를 정하고 **비교 기간 B**를 고르면(직전 기간 / 작년 같은 기간 / 직접 입력)
  지표별 증감(수·%, 가동률은 %p)과 구간별 나란히 비교표가 나옵니다.
- **객실 분류**(상품관리에서 지정: 2인실·4인실·독채 등)를 골라 그 분류만 보거나, **분류별 표**에서 분류마다와 합계를 한눈에 비교합니다.
- **객실별 가동률**(판매일수 ÷ 일수)과 **요일별 가동률**도 함께 봅니다. 엑셀(기간A·기간B·비교·분류별·객실별·요일별 시트)과 인쇄 지원.
- 가동률 = 판매 객실 ÷ (객실 수 × 일수). 객실 수는 상품관리에서 **'판매' 중인 객실** 수입니다.

## 6. 매출통계 · 엑셀 · 인쇄

- **운영관리 › 매출통계** 메뉴
  - 매출 통계: **기간별**(일자별, 최대 1년) / **월별**(연도 선택) / **연간**
    - 입장권 유료·무료 매수, 금액, 현금·카드 / 판매 객실·입실 인원·금액 / 상품권 환급 / 매출 합계
    - 입장권별·객실별 합계 (객실은 비수기 평일·비수기 주말·성수기별 판매수, 할인 건수 포함)
  - 업무일지: 기간 내 업무일지(업무내용·특이사항) 목록
  - '결재완료만' 체크 시 결재가 끝난 문서만 집계
- **엑셀 다운로드**: 화면과 같은 내용을 .xlsx로 받습니다 (매출은 요약·입장권별·객실별 3개 시트).
  호스팅에 PHP zip 확장이 없으면 CSV로 받아지며, 엑셀에서 그대로 열립니다.
- **인쇄 / PDF 저장**: 인쇄 버튼 → 인쇄 창에서 대상(프린터)을 **'PDF로 저장'**으로 고르면 PDF 파일이 됩니다.
  통계는 A4 가로로 인쇄되고, 모든 인쇄물 상단에 사이트명·제목·출력일시·출력자가 찍힙니다.
- 인쇄 버튼이 있는 화면: 매출통계, 일지 달력, 일지 상세(결재란 포함), 상품권 수불부, 시설물 목록·상세, 장비 목록·상세

## 8. 보안 기본사항 (구현됨)

- 비밀번호 `password_hash()` 저장, 로그인 시 세션 ID 재발급
- 모든 쿼리 PDO Prepared Statement (SQL 인젝션 방지)
- 모든 출력 `htmlspecialchars` 처리 (XSS 방지)
- 모든 POST 요청 CSRF 토큰 검사
- `app/`, `sql/` 폴더 및 `.sql/.md` 파일 웹 접근 차단 (`.htaccess`)
- 세션 쿠키 HttpOnly / SameSite=Lax / https 시 Secure

> 호스팅이 Apache가 아닌 nginx라면 `.htaccess`가 적용되지 않습니다.
> 이 경우 `app/` 파일들은 직접 열어도 아무것도 출력하지 않도록 되어 있지만,
> 호스팅 업체에 `app`, `sql` 폴더 접근 차단을 요청하세요.
