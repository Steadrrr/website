# 체험판(데모) 사이트 — `/www/demo/`

운영 사이트(`/www/`)는 그대로 두고, 같은 호스팅의 `demo` 폴더에 체험판을 올린다.
**서버에서 따로 할 일은 없다** (DB 추가·설정 파일 올리기 필요 없음).

## 어떻게 동작하나
- 체험판 폴더에는 `app/config.php` 가 없고, `app/config.demo.php` 가 운영 사이트의 `/www/app/config.php` 를 읽어
  DB 접속 정보만 빌려 쓴다 (`'demo' => true`, `base_url` `/demo`, 사이트 이름 「쉬자ON」).
- 같은 DB 안에서 표 이름 앞에 `demo_` 가 붙은 별도 표(`demo_users`, `demo_journals` …)만 쓴다 (`app/demo_db.php`).
  - 모든 SQL 이 표 이름을 `demo_` 표로 바꾼 뒤 실행된다. 운영 표 이름이 남은 채로 표를 만들거나 지우려 하면 실행하지 않는다.
  - 로컬 검증: 운영·체험판을 같은 DB 로 띄워 체험판 전체 화면 열기·저장·초기화 후 운영 표 50개의 CHECKSUM 이 그대로임을 확인 (2026-10-22).
- 첫 접속 때 `demo_` 표를 만들고 가상 자료를 채운다 (몇 초). 날짜가 바뀐 뒤 첫 접속 때마다 처음 상태로 돌아간다.
- 로그인 쿠키 이름이 달라 운영 사이트 로그인과 섞이지 않는다.
- 진단·설치 화면(check.php·diag.php·install.php)은 체험판에 올리지 않는다.

## 배포
- `contest` 브랜치에 커밋 메시지 `[데모배포]` 가 들어간 커밋을 올리면 Actions 가 `/www/demo/` 에 FTP 업로드.
- 체험판을 없애려면: 서버의 `/www/demo/` 폴더를 지우고, DB 에서 `demo_` 로 시작하는 표를 지우면 된다 (운영 표는 그대로).
