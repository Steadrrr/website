1. 개발 배경

 가. 기록은 많은데 여기저기 흩어져 있음
  □ 같은 고장이 단톡방·민원대장·만족도 조사·시설물 대장에 따로 기록됨
   ○ 예) 숲B 객실 온수 고장(2026. 6.): 단톡방 2회, 민원대장 2줄, 만족도 조사 1건 → 시설물 대장에는 기록 없음
  □ 업무 단톡방이 사실상 시설 대장 역할
   ○ 9개월 메시지 3,751건 중 시설 보고 약 345건 → 시설물 대장에 남은 2026년 이력은 1건

 나. 기록이 중간에 끊기고 분류가 제각각
  □ 민원대장 처리일자 누락 72%, 전화 응대 현황 분류 누락 61%, 시설 보수 대장 조치일자 누락 55%
  □ 장부마다 분류 기준이 다름 (민원대장 3가지, 전화 현황 12가지, 보수 대장 자유 입력)

 다. 손으로 하는 반복 작업이 많음
  □ 지역상품권 환급액(연박·주말·성수기·할인 조건)을 손으로 계산, 수불부를 손으로 작성
  □ 퇴실·청소완료를 무전·전화로 전달, 매출·객실 실적을 엑셀에서 다시 옮겨 적음

 라. 그 결과, 같은 고장이 반복돼도 미리 알기 어려움
  □ 객실 온수보일러 고장 14건(8개 객실), 1호 관정 장애 5회 등 → 고객 객실 변경까지 발생


2. 주요 내용

 가. 업무 흐름 하나로 연결
   기록(현장) → 공유(실시간) → 확인(결재) → 축적(데이터) → 예측(AI)

 나. 6개 업무 묶음
  ① 기록·결재: 업무일지·매출보고 작성 → 결재선 자동 지정, 일괄 결재, 수정 이력 자동 기록
  ② 객실 운영: 예약 엑셀을 올리면 객실 판매 자동 입력, 청소관리 휴대폰 앱(퇴실처리 → 청소완료 알림), 소모품 재고
  ③ 재정·상품권: 지역상품권 환급액 자동 계산, 금고 불출·반납, 수불부 서명·A4 인쇄, 매출 엑셀 가져오기
  ④ 시설·안전: 시설점검, 시설물·장비별 고장·수리 이력과 비용, 물품구매
  ⑤ 고객: 민원 3단계 분류(대·중·소) 입력과 처리 상태 관리, 민원 통계, 유실물, 입장객 통계
  ⑥ 프로그램: 프로그램 일정, 산림치유·유아숲·숲해설 운영보고 → 실적 통계 자동 집계

 다. AI 활용 기능
  □ AI 분석 – 오늘부터 4주 미리 보기
   ○ 어제까지 쌓인 민원·고장·소모품 기록을 시스템이 숫자로 계산 → AI가 읽고 '미리 챙길 일'을 정리
   ○ 중요한 순서대로 예상 문제·근거·미리 할 일, 소모품 구매 목록 초안(최근 단가 × 수량), 이번 주 할 일
   ○ 하루 한 번 발행(주무관 이상), 발행본은 전 직원이 함께 봄 / 1회 비용 약 150원
  □ 민원 자동 분류 제안
   ○ 민원 내용을 적고 버튼을 누르면 대·중·소 분류와 장소(객실 이름)를 자동으로 골라 줌 → 담당자는 확인만
   ○ 실제 2026년 객실 민원 47건으로 시험한 결과 46건 정확 분류
  □ 지난 예측 되돌아보기 (적중 확인)
   ○ 지난 날짜를 고르면 그날까지 기록만으로 예측 → 그 뒤 4주 실제 기록과 자동 비교 (일어남 / 비슷함 / 안 일어남)
   ○ 예측을 믿을 수 있는지 직원이 직접 확인 (추가 비용 없음)

 라. AI를 안전하게 쓰는 원칙
  □ 계산은 시스템, 해석은 AI → AI가 숫자를 지어내지 않도록 근거 숫자를 화면에 함께 표시
  □ AI에는 통계 숫자만 보냄 (민원 원문은 보내지 않고 전화번호·이메일·이름은 자동으로 가림)
  □ 최종 판단은 담당자가 함


3. 실제 기록으로 검증한 결과

 □ 2024~2026년 실제 기록(보수 대장·민원대장·만족도 조사 등) 335건으로 "그때 예측했다면?" 시험
 □ 미리 경고할 수 있었던 사례
  ○ 해B 2층 에어컨: 2025. 6~7월 3주 사이 3회 고장 → 2026. 4월 '재발 주의' → 실제 7. 18. 민원 발생
  ○ 1호 관정: 2024. 6~7월 3회 장애 → 9. 2. 경고 → 실제 9. 23. 압력탱크 교체
  ○ 제설기: 2024. 11~12월 2회 고장 → 경고 → 2025. 2월 사용 불가, 새로 구입
  ○ 벌집: 2026. 5. 9. 민원 2건 → 경고 → 실제 5. 15.~6. 28. 벌집 6건, 쏘임 사고 1건
 □ 시사점
  ○ 기록만 남아 있으면 같은 설비가 또 고장 나는 것은 미리 알 수 있음
  ○ 기록이 흩어지고 이름이 제각각이면 예측이 어려움 → 쉬자ON은 같은 이름·같은 분류로 기록이 쌓여 쓸수록 정확해짐


4. 실제 사용과 개선 기록

 □ 현장에서 2주 이상 실제 업무에 쓰며 시험한 작품
  ○ 2026. 9. 22. 첫 버전 이후 직원들이 매일 업무일지·매출보고·객실판매·청소관리·상품권·민원 입력에 사용
 □ 쓰면서 나온 요청을 바로 고치고, 업데이트 100건 이상을 날짜별로 기록
  ○ 예) 여러 객실 한 번에 퇴실처리, 상품권 환급 규칙(주중 할인·업무예약 제외) 반영, 결재 상신 취소, 입퇴실 현황 A4 한 장 인쇄
  ○ 담당자가 말로 요청 → AI가 프로그램 수정 → 대부분 당일 반영 (바이브 코딩)
 □ 업데이트 기록은 '기타 › 업데이트' 화면에서 누구나 확인 가능
  ○ 체험판도 운영 사이트와 같은 프로그램이라, 체험판 업데이트 화면에 실제 개선 기록(날짜·내용)이 그대로 남아 있음
 □ 운영 반영 전 점검: 화면 828개(운영·체험판 × 직급 4종 × PC·휴대폰)를 확인하고 보안 점검을 거쳐 반영


5. 활용 방법

 가. 체험판 접속
  □ 주소: https://(주소)/demo → 로그인 화면에서 역할 선택 (비밀번호 없음)
  □ 역할: 사원 김숲 / 공무직 이나무 / 주무관 박하늘 / 팀장 최산림
  □ 자료는 모두 가상 (실제 객실 19실·고장 이력·계절별 민원 모양을 본뜸), 매일 밤 처음 상태로 돌아감 → 마음껏 입력해도 됨

 나. 3분 체험 순서 (권장)
  ① 사원: 업무일지 작성 → 민원 입력에서 '✨ 분류 제안' 눌러 보기 → 결재 올리기
  ② 공무직: 청소관리(휴대폰)에서 퇴실처리·청소완료 → 객실판매에서 상품권 환급액 자동 계산 확인
  ③ 주무관: 결재함에서 일괄 결재 → '✨ AI 분석'에서 오늘부터 4주 예측 보기
  ④ 팀장: 'AI 분석 › 지난 예측 되돌아보기'에서 과거 예측과 실제 비교 → 통계 화면

 다. PC·휴대폰 모두 사용 (설치 없이 인터넷 주소로 접속, 청소관리는 홈 화면에 추가해 앱처럼 사용)


6. 기대 효과

 □ 업무 시간 단축: 엑셀·수기 재입력 → 엑셀 올리기·자동 계산, 무전·전화 전달 → 휴대폰 알림
 □ 정확성: 상품권 환급·수불부 자동 계산으로 계산 실수 방지, 결재·수정 이력 자동 기록
 □ 데이터 행정: 민원·고장이 같은 분류로 쌓여 통계·예측 자동 → 예방 정비, 성수기 전 소모품 구매 계획
 □ 고객 서비스: 반복 고장을 미리 고쳐 객실 변경 등 고객 불편 감소
 □ 인수인계: 담당자가 바뀌어도 이력이 그대로 남음
 □ 비용: 개발비 0원, AI 사용료 1회 약 150원, 기존 호스팅 그대로 사용


7. 보안·개인정보 보호

 □ 직급(사원·공무직·주무관·팀장)과 메뉴별 권한 → 권한 없는 메뉴는 AI 결과에서도 숨김
 □ 예약 엑셀은 필요한 칸(인원·할인 여부)만 읽고 파일은 바로 삭제 → 고객 이름·연락처 저장 안 함
 □ AI에는 통계 숫자만 보내고 개인정보는 자동으로 가림, AI 이용 키는 서버에만 보관
 □ 체험판은 운영 자료와 완전히 분리 (가상 자료, 별도 로그인)


8. 확산 가능성 및 향후 계획

 □ 확산: 군내 휴양림·캠핑장·체육시설 등 시설 운영 부서에 그대로 적용 가능 (객실·분류·메뉴를 설정 화면에서 변경)
 □ 다음 단계(V2) – 스마트 체크인 (현재 기획 단계)
  ○ 1단계(비용 거의 없음): 객실 QR 하나로 이용 안내·물품 요청·고장 신고(사진)·웹 퇴실·만족도 조사 → 청소관리·민원·장비 이력과 자동 연결
  ○ 2단계: AI 챗봇이 예약·입퇴실 문의(전화 문의의 약 60%) 응답, 요청은 민원 자동 분류로 접수, 긴급 건은 당직 전화로 연결
  ○ 3단계(예산 필요): 기간 한정 비밀번호 스마트 도어락, 차량번호 주차차단기 연동, 보일러 차단기 이상 알림 센서
  ○ 고객 정보는 휴대폰 번호·차량번호만 쓰고 처리 후 바로 삭제
